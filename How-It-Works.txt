HOW IT WORKS - Get-Fleet-Qualys-Installed&Status.ps1
======================================================

WHAT IT DOES
For every VM in C:\Temp\vmlist.txt, it checks whether the Qualys Agent and the
Binalyze AIR Agent are installed, and if installed, whether their service is
running. Both products are checked independently per VM.

HOW IT CHECKS (no WinRM, no SSH)
- Uses vCenter + VMware Tools (Invoke-VMScript / Guest Operations) to run a
  small check script directly inside each VM.
- OS (Windows/Linux) is auto-detected per VM from VMware Tools; the matching
  PowerShell or Bash check runs automatically.

WINDOWS CHECK LOGIC
- Qualys: Get-Service "QualysAgent" + uninstall registry entries matching
  "*Qualys*".
- Binalyze: Get-Service "Binalyze.AIR.Agent.Service" (falls back to any
  service named/displayed "*Binalyze*") + uninstall registry entries matching
  "*Binalyze*".

LINUX CHECK LOGIC
- Qualys: systemctl unit list + rpm/dpkg package list, matched on "qualys".
- Binalyze: systemctl unit list + rpm/dpkg package list, matched on
  "binalyze".

VALIDATION BEFORE CHECKING (per VM)
1. VM exists in vCenter
2. VM is powered on
3. VMware Tools is running
4. Guest OS detected (Windows or Linux)
If any of these fail, the VM is recorded as Failed with a reason instead of
being checked.

RESULT FIELDS (per successful VM)
ServerName, IPAddress, OS, QualysInstalled, QualysAgentStatus, QualysVersion,
BinalyzeInstalled, BinalyzeAgentStatus, BinalyzeVersion
Values used: Installed / Not Installed, Running / Not Running, N/A.

OUTPUT
- Console table with both products side by side.
- Summary: total checked, succeeded, failed, and a failure-reason breakdown.
- Two CSVs in C:\Temp\Fleet:
   Security_Agents_Check_Success.csv
   Security_Agents_Check_Failed.csv

PREREQUISITE FILES/FOLDERS
- C:\Temp\vmlist.txt   -> you must create this (one VM name per line).
- C:\Temp\Fleet        -> created automatically by the script if missing.
- No CSV needs to be prepared beforehand - CSVs are only produced as output.

READ-ONLY GUARANTEE
The script only reads service/process/registry/package state. It never
installs, starts, stops, restarts, or reconfigures Qualys or Binalyze, and
never changes vCenter settings.
