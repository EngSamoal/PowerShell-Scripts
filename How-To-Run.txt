HOW TO RUN - Get-Fleet-Qualys-Installed&Status.ps1
====================================================

PREREQUISITES
1. Run from a Windows machine with VMware PowerCLI installed.
2. Create the VM list file:  C:\Temp\vmlist.txt
   - One VM name per line (exact name as shown in vCenter).
3. Output folder C:\Temp\Fleet will be created automatically if missing.
4. Have ready:
   - A Windows local admin credential (only needed if the list has Windows VMs)
   - A Linux root/sudo-capable credential (only needed if the list has Linux VMs)

STEPS
1. Open PowerShell (run as Administrator, so DNS auto-fix for ESXi hosts works).
2. Connect to vCenter:
   Connect-VIServer -Server your-vcenter-fqdn
3. Run the script:
   C:\Users\Samoal\Downloads\Get-Fleet-Qualys-Installed&Status.ps1
4. When prompted, enter the Windows credential and/or Linux credential
   (only asked once each, only if that OS type is present in vmlist.txt).
5. Wait for it to finish. Results print to the console as it goes.

OUTPUT
- C:\Temp\Fleet\Security_Agents_Check_Success.csv  (VMs successfully checked)
- C:\Temp\Fleet\Security_Agents_Check_Failed.csv    (VMs that failed, with reason)
(A CSV is only created if it has at least one row.)

NOTES
- This script is read-only. It does not install, start, stop, or change anything
  on the VMs or in vCenter.
- If a VM fails with a DNS/communication error, the script tries to auto-fix it
  by adding the ESXi host to your local hosts file - needs PowerShell as Admin.
